BOSS直聘智能岗位投递系统开发文档
1. 项目概述
1.1 项目简介
本项目为一套一体化智能求职投递管理系统，由Chrome/Edge双端浏览器插件、后台管理系统、禾蛙平台爬虫模块、AI岗位分析模块四部分组成。系统支持用户插件端自主注册、登录授权使用，核心实现后台精细化管控不同插件账号的可投递岗位，插件端完成BOSS直聘岗位批量一键投递；同时后台具备客户管理、爬虫周期定时提醒、全量操作日志记录、超级管理员权限管控功能，结合禾蛙平台岗位爬虫筛选与AI接口自动生成岗位分析报告，实现岗位获取、分配、投递、数据分析全流程自动化。
1.2 核心功能亮点
双浏览器兼容：一套插件代码适配谷歌Chrome、微软Edge主流浏览器
自主账号体系：插件端支持用户注册、后台审核授权、账号登录使用
精细化岗位管控：后台独立分配不同账号的可投递岗位，权限精准隔离
批量自动化投递：插件支持岗位勾选、全选/取消全选、一键批量投递
全流程数据管理：后台客户管理、定时爬虫提醒、操作日志溯源
智能数据分析：禾蛙平台岗位筛选爬虫+AI自动生成岗位分析报告
1.3 技术架构
浏览器插件：Manifest V3 规范，适配Chrome、Edge双端
后端服务：SpringBoot + MySQL + Redis
爬虫模块：定向抓取禾蛙平台岗位数据，支持多条件筛选
AI模块：对接第三方大模型接口，自动生成标准化分析报告
2. 浏览器插件功能需求
2.1 基础兼容规范
插件采用行业通用Manifest V3版本开发，无需区分两套源码，天然兼容谷歌Chrome、微软Edge主流浏览器，支持新旧版本浏览器适配，打包后可直接在双浏览器中加载使用，保证用户通用性体验。
2.2 账号体系功能（注册+登录）
2.2.1 插件注册功能
插件端独立提供注册入口，新用户可自主提交注册信息，无需后台手动创建账号，具体规则如下：
注册字段：用户名/手机号、登录密码、确认密码、所属客户/公司名称
注册流程：用户填写信息提交 → 后台自动生成待审核账号 → 超级管理员后台审核
账号状态：新增注册账号默认待审核，审核通过后方可登录使用；审核拒绝/账号禁用时，插件弹窗提示账号状态异常，无法使用任何业务功能
数据校验：前端实时校验手机号格式、密码一致性、必填项完整性，避免无效注册提交
2.2.2 插件登录功能
登录方式：账号+密码登录，校验通过后后端下发唯一Token凭证
凭证存储：Token加密存储于浏览器本地缓存，实现持久化登录，关闭插件不失效
权限拦截：未登录、Token过期、账号未审核/已禁用状态，自动拦截所有投递、查询功能，强制跳转登录页面
退出登录：支持手动退出，退出后自动清空本地Token，锁定全部业务功能
2.3 核心岗位投递功能
2.3.1 后台岗位下发机制（核心管控）
插件所有可投递岗位完全由后台管理系统统一管控下发，用户无法自主搜索任意岗位投递，实现精准权限控制：
登录拉取：用户插件登录成功后，自动请求后端接口，拉取当前账号专属的可投递岗位列表
独立权限：不同插件账号获取的岗位列表相互隔离，仅可查看、投递后台分配的岗位
数据展示：插件展示岗位核心信息，包含岗位名称、招聘公司、薪资区间、工作地点、岗位来源
2.3.2 岗位勾选管理
单选功能：每个下发岗位配备独立勾选框，支持单独选中/取消选中
全选功能：提供一键全选、一键取消全选按钮，批量操作当前所有可投递岗位
状态缓存：页面勾选状态临时缓存，切换数据、刷新页面不丢失勾选记录
2.3.3 一键批量投递
触发条件：至少勾选1个有效未投递岗位后，一键投递按钮解锁可用
投递逻辑：插件自动跳转BOSS直聘对应岗位页面，模拟人工操作，依次完成岗位沟通、简历投递、发起求职申请等流程
结果上报：投递完成后实时统计投递结果（成功、失败、岗位关闭、已投递），自动同步至后台数据库留存记录
防重复投递：自动校验岗位投递状态，已投递岗位禁止重复发起投递
2.4 插件辅助能力
插件内置页面监听、异常捕获机制，投递过程中遇到页面加载失败、网络异常、岗位下架等问题，自动终止当前任务并记录异常日志，同步至后台，便于管理员排查问题。
3. 后台管理系统功能需求
3.1 用户管理模块
统一管理所有插件注册用户（客户）全量信息，实现客户账号全生命周期管控：
客户信息管理：展示客户账号、所属公司、注册时间、账号状态、绑定岗位数量、累计投递数据等核心信息，支持新增、编辑、查询
账号审核管理：对插件端注册的新账号进行审核通过/驳回操作，支持手动启用、禁用已有账号
数据统计：统计单个客户及全量客户的投递成功数、失败数、待投递岗位数等数据
条件筛选：支持按注册时间、账号状态、公司名称等多维度筛选客户数据
3.2 精细化岗位分配管控模块（核心）
3.2.1 岗位资源池管理
后台搭建统一公共岗位资源池，汇聚所有可投递岗位，数据来源包含禾蛙爬虫自动抓取、后台手动新增、Excel批量导入三种方式，支持岗位信息编辑、上下架、删除、查询管理。
3.2.2 多方式岗位分配
支持灵活的岗位分配模式，适配不同管控需求：
单账号单独分配：针对指定插件账号，精准绑定专属投递岗位
批量账号分配：选中多个客户账号，统一批量分配相同岗位资源
条件智能分配：按岗位城市、薪资、岗位类型、经验要求等条件，自动匹配岗位下发至对应账号
3.2.3 投递权限管控
实时管控：后台可随时新增、替换、清空账号的可投递岗位，即时生效
任务终止：可手动暂停、终止指定账号的投递权限，锁定岗位投递功能
状态追踪：实时查看岗位下发状态、投递中、已完成、投递失败等状态
3.3 爬虫周期定时提醒功能
自定义周期：支持为不同客户单独配置爬虫执行周期，可选每日、每周、每月自定义时间执行
自动提醒：到达预设周期时间，后台自动生成提醒消息，告知管理员执行禾蛙岗位爬虫更新
任务管控：支持定时任务启用、暂停、删除，记录每一次任务执行、提醒日志
数据联动：爬虫更新的新岗位，可快速批量分配至对应客户账号
3.4 全量操作记录模块
系统全程记录所有操作行为，日志永久留存、不可删除，支持溯源查询：
记录范围：用户注册、账号审核、岗位分配、插件投递、爬虫执行、AI报告生成、后台管理员所有增删改查操作
日志字段：包含操作人、操作时间、操作IP、操作内容、关联客户、操作结果
检索能力：支持按时间区间、操作类型、操作人、客户信息多维度筛选查询
3.5 管理员权限体系
3.5.1 主管理员（超级管理员）
拥有系统最高全部权限，无操作限制：
账号管理：审核、启用、禁用所有插件客户账号，新增、管理普通管理员账号
岗位管控：全权负责岗位池维护、所有账号岗位分配与权限管控
系统配置：配置AI接口密钥、爬虫参数、定时任务规则、系统基础参数
数据查看：查看全量客户数据、投递记录、操作日志、AI分析报告
3.5.2 普通管理员
权限受限，仅可操作超级管理员分配的权限范围：仅管理指定客户、查看对应投递数据与日志、配置对应客户爬虫定时任务，无系统参数配置、账号新增、全量数据查看权限。
4. 禾蛙爬虫与AI分析模块
4.1 禾蛙平台爬虫功能
4.1.1 多条件岗位筛选
爬虫支持自定义筛选字段，精准抓取目标岗位数据，筛选条件包含：岗位名称、工作城市、薪资区间、工作经验、学历要求、行业分类、岗位发布时间等。
4.1.2 爬虫触发方式
手动触发：管理员后台手动一键启动爬虫任务，即时抓取岗位数据
定时触发：根据客户配置的爬虫周期，自动定时启动爬虫任务
4.1.3 数据处理
爬虫抓取的合规岗位数据自动入库至系统岗位资源池，自动去重、过滤无效下架岗位，为后台岗位分配提供数据支撑。
4.2 AI接口智能分析报告
接口配置：后台可配置第三方AI接口地址、密钥、参数，统一管理AI服务
数据入参：批量提取爬取的岗位JD详情、薪资、企业、行业等核心数据，封装后调用AI接口
报告内容：AI自动生成标准化分析报告，包含行业薪资走势、岗位需求热度、核心技能要求、求职难度分析、企业招聘画像等内容
报告管理：报告自动绑定对应客户，支持在线预览、下载留存，后台可查询所有历史报告
5. 核心业务流程
用户下载安装Chrome/Edge插件，自主填写信息完成账号注册，账号进入待审核状态；
超级管理员后台审核通过账号，激活账号使用权限；
用户登录插件，自动拉取后台分配的专属可投递岗位列表；
用户在插件端勾选岗位、全选批量选择，触发一键投递功能；
插件自动跳转BOSS直聘完成岗位投递，实时同步投递结果至后台；
后台通过禾蛙爬虫定时/手动抓取新岗位，更新岗位资源池并分配至对应客户；
系统基于爬取的岗位数据，调用AI接口生成分析报告，全程留存操作日志与数据记录。
6. 数据库核心表设计
plugin_user（插件用户表）：存储插件注册用户信息、账号状态、登录凭证、所属客户信息
sys_admin（管理员表）：存储超级管理员、普通管理员账号、权限标识信息
customer（客户表）：客户基础信息、套餐状态、绑定账号、统计数据
job_pool（岗位资源池表）：存储所有可分配投递的岗位基础数据
user_job_relation（账号岗位关联表）：核心关联表，记录每个插件账号对应的可投递岗位
deliver_record（投递记录表）：记录所有插件账号的岗位投递结果、时间、状态
cron_task（定时任务表）：存储各客户爬虫周期配置、任务状态、执行记录
operation_log（操作日志表）：存储系统全量操作日志，永久留存
hewa_job（禾蛙爬虫岗位表）：存储爬虫抓取的原始禾蛙岗位数据
ai_report（AI分析报告表）：存储生成的AI岗位分析报告内容、关联客户、生成时间
7. 非功能性需求
安全性：用户密码加密存储、接口请求验签、Token加密传输、账号权限隔离、日志不可篡改删除
稳定性：投递失败自动重试、爬虫异常捕获、AI接口超时降级、网络异常容错处理
扩展性：支持后续新增招聘平台投递功能、新增多AI模型切换、拓展更多爬虫筛选条件
兼容性：插件完美适配主流Chrome、Edge浏览器，兼容新旧版本内核
8. 部署方案
后端服务：服务器部署Golang项目，搭配postgresql数据库、Redis缓存，Nginx反向代理
浏览器插件：源码打包CRX格式，支持本地调试加载，可适配浏览器应用商店上架
爬虫服务：独立任务服务部署，支持定时调度、异常重启，保障数据抓取稳定性
AI服务：外网对接第三方AI接口，配置限流、重试机制，保障报告生成稳定性
