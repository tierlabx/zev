## Zev UI Design System v2 — 完整设计方案

为 Zev 开源项目创建了全新的 UI 设计方案，核心要点：

### 品牌色彩体系
- 从 Logo 几何狼头提取 Slate 银灰色阶作为结构色（9 级）
- Steel Blue (#2563EB) 替换原 Ant Design #1677FF 作为动作色
- Amber (#F59E0B) 作为"狼眼"点缀色（通知/警告）
- 完整的 CSS Variable 实现 + 暗色模式映射

### 动画优先体系（四层编排）
1. **Micro interactions** (50-150ms): 按钮、输入框、图标微交互
2. **Content transitions** (200-400ms): 路由切换、模态框、抽屉
3. **Layout animations** (300-500ms): 侧边栏折叠、列表排序、FLIP
4. **Ambient effects** (continuous): Three.js 背景、骨架屏、数字递增

### 关键设计决策
- Dashboard 从空白占位改为：统计卡片(stagger入场) + 趋势图(path draw) + 活动流 + 系统健康
- Sidebar active 指示器用 Framer Motion layoutId 实现滑动药丸
- 所有动画遵循 prefers-reduced-motion
- 排版仅用 400/500 两个字重，避免数据密集界面的视觉噪音

## 动态路由生成

### 核心改动

将前端路由从硬编码静态定义改为从后端菜单数据自动生成：

**组件注册表 (`src/router/components.tsx`):**
- 后端 component 字段（如 `dashboard/index`）到 `React.lazy()` 组件的映射
- `withSuspense()` 包装提供统一加载占位
- 新增页面只需在此注册，无需修改路由代码

**动态路由生成器 (`src/router/routes.tsx`):**
- `buildRouteTree(menus)` 递归遍历菜单树生成 TanStack Router 路由
- M 目录 → 父路由 + 递归子路由 + index 重定向到第一个子页面
- C 菜单 → 带 lazy 组件的路由
- F 按钮 → 跳过（仅用于权限控制）
- splat 路由兜底重定向到第一个可用页面

**路由器工厂 (`src/router/index.tsx`):**
- 模块加载时从 zustand persist 同步读取 menus
- 调用 `buildRouteTree()` 构建完整路由树

**认证流程更新:**
- 登录成功 → `window.location.href = firstPage` 触发页面重建路由树
- 退出登录 → `window.location.href = "/login"` 触发重建
- 401 响应 → `window.location.href = "/login"` 替代 `router.navigate`
- 页面刷新 → 从 persist 读取 menus 动态构建路由

**新增页面:**
- `src/pages/Profile.tsx` — 个人中心（用户信息 + 权限标识展示）
- `src/pages/NotFound.tsx` — 404 页面（动画入场 + 回到首页）

**辅助改动:**
- `src/lib/menu-utils.ts` — 共享 `findFirstPagePath()` 工具
- `src/store/tags.ts` — 移除硬编码初始 dashboard 标签
- `tags-view.tsx` — 回退导航使用动态首页路径
- `DashboardLayout` — 检测 menus 从空到有时自动 reload 重建路由
- `account-dropdown.tsx` — 个人中心导航到 `/profile`
- `request.ts` — 移除 router 依赖，401 用 `window.location.href`

### 设计决策

1. **页面刷新重建路由**：登录/退出用 `window.location.href` 而非 SPA navigate，确保路由树从更新后的 store 完整重建
2. **persist 同步读取**：zustand persist 在模块加载时同步恢复 localStorage 数据，无需异步等待
3. **代码分割**：所有页面通过 `React.lazy()` 懒加载，Vite 构建确认每页面独立 chunk
